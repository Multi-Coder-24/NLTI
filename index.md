# Getting Started With Next Level Twitch Integration

Welcome to NLTI V5 where I have made significant changes from V4 so a new Wiki is in order.
To begin with this mod still has the same features you love and even has some hermitcraft easter eggs embedded too.
This mod is now making use of a new authorization mechanism provided by twitch and no longer relying on a third party for you to visit and copy your token into.
That means you now only have to authorize the web pop up and this mod will handle the rest. I want to take this moment and thank you for your patience whilst I've been away and pre-occupied with IRL issues.

## Connecting to twitch

In order for NLTI to connect to your twitch account you need to authorize the app itself.
To do this start the world you intend to use and run the command
**/NLTI Link** This command will paste a message in chat with the title of click me, click the message to open the authorization URL in your computers web browser, behind the scenes the mod will start a quick web server to handle the reply sent from the authorization URL. Once this has been done you will recieve a message in chat saying that the link has been successful or not.
Should the link fail you can retry the authorization, if the failure persists please create an issue and I will look into it.
If the link succeedes you can now close the world and then re-open the world as the twitch connection handles when the server has started (in singleplayer your world is a dedicated server) which is when the world opens and you have joined it. For servers you will need to restart the server for the change to take effect.

## Using The Mod

To start the NLTI mod fully it is as simple as running **/NLTI Start**
If anything breaks you can reset the mod by using **/NLTI Reset**
To Stop the mod you use **/NLTI Stop**
